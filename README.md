Fly the little red prop plane across the Indonesian archipelago: thread the golden rings, mind your fuel, dodge the storm clouds, and land gently on each island's runway to finish the three-leg tour. A complete 2D canvas flight game — throttle and pitch physics with stalls, wind and gusts, fuel and hull management, three missions, and a lit HUD (altitude, speed, heading, fuel, hull, score).

## Run it

```sh
python3 -m http.server 8080 --directory game
# then open http://localhost:8080 in desktop Chrome
```

Play with keyboard: ↑ / ↓ pitch, ← / → throttle, Space to fly, P to pause, M to mute. No network, no build step — plain static files under `game/`.
